# 4 · Heal what broke

For every broken selector, Selector Healer scans the live DOM for the element you *meant* and proposes ranked, **explainable** fixes.

You get, on each card:

- **Why it broke** - e.g. *"text changed from 'Log in' to 'Sign in'"*
- **All candidate fixes**, each with a confidence and a **"Why NN%?"** per-rule breakdown
- **Diff preview** before you apply, and **one-click Undo** after

Apply a fix from the **dashboard**, a **Quick Fix** (`Ctrl+.`), or a **CodeLens** - or **Skip** a selector to set it aside.

Everything is reversible, and every change is AST-based (your formatting and comments are preserved).
